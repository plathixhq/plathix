# Grid View

## What It Does

Shows media files as thumbnails in the standard WordPress grid. When a folder is selected in the Plathix sidebar, the grid filters to show only the files in that folder.

## How It Works

1. Open **Media → Library** (default view is grid).
2. The Plathix sidebar appears on the left.
3. Click a folder to filter the grid to that folder's contents.
4. Click **All Files** in the sidebar to clear the filter and see everything.
5. Drag files from the grid onto a folder in the sidebar to move them.

## Notes

- The grid shows only files directly in the selected folder. Files in subfolders are not shown unless you navigate into them.
- Infinite scroll loads more files automatically as you scroll down. See [Infinite scroll](../folders/infinite-scroll.md).
- The same folder filtering applies inside the media uploader modal when inserting media into posts and pages.
