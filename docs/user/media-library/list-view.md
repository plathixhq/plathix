# List View

## What It Does

Shows media files in the WordPress list table format, with an added **Folder** column that shows which folder each file belongs to. Clicking a folder in the sidebar filters the list to that folder's contents.

## How It Works

1. Open **Media → Library** and switch to list view (the list icon in the top-right of the screen).
2. The Plathix sidebar appears on the left.
3. Click a folder in the sidebar to filter the list to that folder.
4. The **Folder** column in the table shows each file's current folder assignment.

## Notes

- The Folder column shows the immediate folder the file is assigned to, not the full path.
- List view pagination works the same as standard WordPress: use the page navigation at the top or bottom of the table.
- Bulk selection in list view uses the standard WordPress checkboxes. See [Bulk actions](bulk-actions.md).
