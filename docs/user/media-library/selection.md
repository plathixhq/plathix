# Select Files

## What It Does

Lets you select one or more files in the media grid to perform bulk actions on them (move, delete, etc.).

## How It Works

**In grid view:**

1. Click a file thumbnail to select it. A checkmark appears on the selected file.
2. Hold **Shift** and click another file to select all files between the two clicks.
3. Hold **Ctrl** (Windows/Linux) or **Cmd** (Mac) and click to add or remove individual files from the selection.
4. Click a selected file again to deselect it.

**In list view:**

- Use the standard WordPress checkboxes at the left of each row.
- Use the checkbox in the table header to select or deselect all files on the current page.

## Selection Indicator

When one or more files are selected, the sidebar toolbar shows a count of selected files and bulk action buttons appear.

## Rules and Limits

- Selection is cleared when you navigate to a different folder.
- Selection is per-page: navigating to a different page of results clears the selection.
- Maximum simultaneous selection is determined by the number of files currently loaded in the grid (all visible files can be selected at once).
