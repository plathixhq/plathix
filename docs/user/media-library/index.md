# Media Library

Plathix extends the standard WordPress media library with folder filtering, enhanced selection, bulk moves, and file replacement.

## What You Can Do

- [Grid view](grid-view.md) — folder-filtered grid with drag-and-drop support
- [List view](list-view.md) — folder column and filtering in the media list table
- [Upload files](upload.md) — upload files directly into a selected folder
- [Select files](selection.md) — select one or more files for bulk actions
- [Bulk actions](bulk-actions.md) — move, delete, or act on multiple files at once
- [Delete media](media-delete.md) — remove files from the library
- [Replace media](replace-media.md) — swap a file while keeping the same attachment ID
- [Attachment events](attachment-events.md) — how Plathix reacts to media library events
