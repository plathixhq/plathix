# Browse the Preset Catalog

## What It Does

Shows all available presets — both built-in ones that ship with Plathix and any custom presets you have uploaded.

## How It Works

1. Go to **Plathix → Presets**.
2. The catalog shows preset cards. Each card displays the preset name, a preview image (if available), and a short description.
3. Click **Apply** on a card to apply that preset's folder structure.
4. Custom presets have a **Delete** option on their card.

## Built-In Presets

Built-in presets ship with the Plathix plugin and cover common site types (photography portfolios, blogs, e-commerce stores, etc.). They are always available and cannot be deleted.

## Custom Presets

Presets you have uploaded via **Upload preset** appear alongside the built-in ones. Only presets with a `valid` status appear in the catalog — invalid presets are hidden.
