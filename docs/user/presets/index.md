# Presets

A preset is a ready-made folder structure you can apply to your media library with one click. Plathix comes with a built-in catalog of presets for common site types (portfolio, blog, e-commerce, etc.). You can also upload your own custom preset packages.

## What You Can Do

- [Apply a preset](apply.md) — apply a preset structure to your media library
- [Upload a custom preset](upload-custom.md) — add your own preset as a `.zip` package
- [Browse the catalog](browse-catalog.md) — view available built-in and custom presets
- [Delete a preset](delete.md) — remove a custom preset from the catalog
- [Reset to scratch](reset.md) — wipe all user-created folders and start fresh

## How Presets Work

Applying a preset creates the folder structure defined in the preset. Existing folders are not deleted unless you choose **Start from scratch** at the same time. If a preset folder name conflicts with an existing folder, a numeric suffix is added automatically.
