# Delete a Preset

## What It Does

Removes a custom preset from the catalog. The preset's folder structure is not deleted from your media library — only the preset definition is removed.

## How It Works

1. Go to **Plathix → Presets**.
2. Find the custom preset you want to remove.
3. Click **Delete** on the preset card.
4. Confirm the deletion.

## Rules and Limits

- Only custom (user-uploaded) presets can be deleted. Built-in presets that ship with Plathix cannot be deleted.
- Deleting a preset does not undo a previously applied folder structure. Folders created by applying the preset remain in the media library.
- Requires `upload_files` capability.
