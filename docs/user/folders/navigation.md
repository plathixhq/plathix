# Navigate the Folder Tree

## What It Does

Lets you browse your folder hierarchy in the sidebar, select a folder to filter the media grid, and expand or collapse subtrees.

## How It Works

- **Click a folder** to select it. The media grid updates to show only the files in that folder (not including subfolders by default).
- **Click the arrow** (▶) next to a folder to expand or collapse its subtrees.
- **Click "All Files"** at the top of the tree to clear the folder filter and show all media.
- **Click "Uncategorized"** to show files not assigned to any folder.
- **Click "Trash"** to open the trash view.

## Filtering Behavior

Selecting a folder filters the media grid to show only files directly assigned to that folder. Files in subfolders are not included unless you navigate into the subfolder.

When used inside the media uploader modal (in a post or page editor), the same sidebar appears and filters the modal's media grid.

## Notes

- The selected folder persists while you stay on the Media Library screen. Navigating away and returning resets the selection.
- On the Posts/Pages list screen (when PRO Content Types is active), the same sidebar appears and filters posts by folder instead of media.
