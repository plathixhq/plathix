# Context Menu

## What It Does

Right-clicking a folder in the sidebar tree opens a context menu with quick actions for that folder.

## Available Actions

| Action | Description |
|---|---|
| New subfolder | Create a new folder nested inside this one |
| Rename | Edit the folder's name inline |
| Set color | Open the color picker to assign or remove a color |
| Delete | Remove the folder (with a confirmation dialog) |

PRO-specific actions (ZIP download, etc.) appear in the same menu when Plathix PRO is active. They are inserted by PRO modules at defined positions.

## How It Works

1. Right-click any folder in the sidebar tree.
2. The context menu appears near the cursor.
3. Click an action to execute it, or click anywhere else to close the menu.

## Rules and Limits

- System folders (Uncategorized, Trash) show a restricted menu — rename and delete are not available for them.
- The context menu closes automatically when you click outside it.
