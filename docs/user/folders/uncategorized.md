# Uncategorized

## What It Does

**Uncategorized** is a built-in system folder that holds all media files not assigned to any user-created folder. Every file in Uncategorized can be moved into a folder at any time.

## When Files End Up in Uncategorized

- Files uploaded without a folder selected in the sidebar.
- Files whose folder was deleted with the "move to Uncategorized" option chosen.
- Files that were never assigned to a folder.
- Files imported from another plugin if the import did not create a matching folder.

## How To Use It

- Click **Uncategorized** in the sidebar tree to filter the media grid to unassigned files only.
- Select files and move them into a folder (drag and drop, or the Move action) to remove them from Uncategorized.

## Rules and Limits

- Uncategorized is a protected system folder — it cannot be renamed, moved, or deleted.
- A file is in Uncategorized whenever it has no folder assignment. There is no explicit "add to Uncategorized" action; just remove a file from all folders and it will appear there automatically.
- The Uncategorized count in the sidebar reflects files without any folder assignment, not files in a folder named "Uncategorized."

## Notes

- Uncategorized is always present and always visible in the sidebar, even if it contains zero files.
- The counter next to "Uncategorized" updates when you navigate to it.
