# Folders

Plathix adds a virtual folder tree to your media library. Folders appear in the sidebar panel on the left side of the Media Library screen and inside the media uploader modal.

## What Folders Are

Folders are WordPress taxonomy terms, not physical directories. Files stay in their original `wp-content/uploads/` location regardless of which folder they belong to. Moving a file between folders changes only a database relationship — URLs and attachment IDs remain unchanged.
