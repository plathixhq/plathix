# Folder Colors

## What It Does

Assigns a color to a folder so it is easier to identify visually in the sidebar tree. The color appears as a colored dot or icon next to the folder name.

## How It Works

1. Right-click a folder and choose **Set color**.
2. The color picker opens inline inside the context menu.
3. Click a color swatch to assign it, or click the "no color" option to remove the current color.
4. The color updates immediately in the tree.

## Rules and Limits

- Any user with `upload_files` capability can set folder colors.
- Colors are stored per folder and are visible to all users.
- Removing a color reverts the folder to the default appearance.
- System folders (Uncategorized, Trash) do not support color assignment.
