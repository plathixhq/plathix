# Sidebar Toolbar

## What It Does

The toolbar at the top of the folder sidebar provides quick actions for managing the folder tree and the current selection.

## Available Buttons

| Button | Action |
|---|---|
| **+ Folder** | Create a new folder at the root level |
| **Collapse all** | Collapse all expanded subtrees in the tree |
| **Expand all** | Expand all folders in the tree |
| **Refresh** | Reload the folder tree from the server |

Plathix PRO may add additional buttons (for example, ZIP download of the selected folder). PRO buttons appear in the same toolbar area, inserted at defined positions.

## Notes

- The **+ Folder** button opens the inline folder creation form at the root level. To create a subfolder, use the [context menu](context-menu.md) on an existing folder instead.
- The toolbar is always visible in the sidebar; individual buttons may be hidden depending on the current view state (for example, when nothing is selected).
