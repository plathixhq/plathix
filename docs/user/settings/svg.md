# SVG Settings

## What It Does

Controls whether SVG file uploads are allowed and configures the safety rules for SVG handling.

## Options

This tab duplicates the settings available in **Settings → SVG** (same options, same effect). For full details see [SVG Upload](../svg-upload/index.md).

### Enable SVG uploads

Toggle to allow or disallow SVG file uploads. Default: **Disabled**.

### Allowed roles

When SVG uploads are enabled, choose which WordPress roles are permitted to upload SVG files. Default: **Administrator** only.

### Safe mode

Applies stricter sanitization rules that remove SVG features commonly used in injection attacks. Recommended for public-facing sites where multiple roles can upload.
