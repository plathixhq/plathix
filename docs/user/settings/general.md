# General Settings

## What It Does

Controls the default behavior of the Plathix sidebar and media grid.

## Options

### Default folder on open

Determines which folder is selected in the sidebar when you open the media library.

| Value | Behavior |
|---|---|
| Last opened folder | Remembers the last folder you selected (per browser session) |
| Specific folder | Always opens the same folder (choose from the dropdown) |
| All Files | Always starts with no folder selected (shows all media) |

### Infinite scroll

- **Enabled** — the media grid loads more files automatically as you scroll down.
- **Disabled** — standard WordPress pagination is used instead (page navigation bar).

Default: **Disabled**.

### Bulk action safe mode

- **Enabled** (default) — bulk actions (like bulk move) show a confirmation dialog before executing.
- **Disabled** — bulk actions execute immediately without confirmation.

## How To Save

After changing settings, click **Save Changes** at the bottom of the page.
