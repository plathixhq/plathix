# Settings

Go to **Plathix → Settings** to configure how Plathix behaves. Settings are organized into tabs.

## Available Tabs

| Tab | What It Configures |
|---|---|
| [General](general.md) | Default folder, infinite scroll, bulk action behavior |
| [Access & Roles](access-roles.md) | Who can use Plathix (basic capability in Free; per-role matrix in PRO) |
| [SVG](svg.md) | SVG upload settings |
| [Trash](advanced.md) | Folder trash retention period |
| Post Types *(PRO)* | Enable folders for posts, pages, and custom post types |

## Notes

- Only users with the `manage_options` capability (Administrators) can access the Settings page.
- Some tabs are added by Plathix PRO when the PRO plugin is active.
