# Add or Remove a Favorite

## What It Does

Marks a folder as a favorite (or removes the mark) so you can quickly navigate to it using the favorites filter.

## How It Works

1. Right-click a folder in the sidebar tree and choose **Add to favorites** (or **Remove from favorites** if it is already marked).
2. A star icon appears next to the folder name when it is a favorite.
3. The change is saved automatically — no extra step needed.

## Rules and Limits

- Favorites are saved per user. Your favorites are not visible to other users.
- You can favorite any user-created folder. System folders (Uncategorized, Trash) cannot be favorited.
- There is no limit on the number of favorites.
