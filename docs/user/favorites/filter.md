# Filter by Favorites

## What It Does

Shows only your favorited folders in the sidebar tree, hiding the rest. Useful when you have a large folder structure and regularly work with a small subset of folders.

## How It Works

1. In the sidebar, click the **Favorites** toggle or tab (the star icon above or near the folder tree).
2. The tree switches to favorites view — only folders marked as favorites are shown.
3. Click a folder to select it and filter the media grid as usual.
4. Click the toggle again (or click **All Folders**) to return to the full tree.

## Notes

- If you have no favorites yet, the favorites view shows an empty state with a prompt to add some.
- Favorites view is per-user — switching to it does not affect what other users see.
- Favorites are folders, not files. You cannot favorite individual media files.
