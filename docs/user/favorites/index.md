# Favorites

Mark folders as favorites to quickly access the ones you use most. Favorites are stored per user — each person in the team has their own list.

## What You Can Do

- [Add or remove favorites](add-remove.md) — mark a folder as a favorite or remove the mark
- [Filter by favorites](filter.md) — view only your favorited folders in the sidebar

## Notes

- Favorites are personal — they are not shared with other users on the site.
- Favoriting a folder does not change the folder's position in the main tree.
