# Search & Filters

Plathix provides two kinds of search and filtering:

- **Folder search** — filter the sidebar folder tree by folder name
- **Media filters** — filter the media grid by folder, file type, or date

## What You Can Do

- [Search folders](search.md) — find a folder by typing its name in the sidebar
- [Media filters](filters.md) — filter the media grid by folder or other criteria
