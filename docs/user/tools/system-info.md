# System Info

## What It Does

Shows diagnostic information about your WordPress environment and Plathix installation. Useful when troubleshooting issues or when support asks for your site's configuration.

## What You See

- **Plathix version** — the installed Free and PRO plugin versions.
- **WordPress version** and **PHP version**.
- **Database status** — whether Plathix's database structures are up to date.
- **Action Scheduler jobs** — the status of background jobs (import, ZIP generation, cleanup).
- **SVG sanitizer** — whether the SVG sanitization library is available and which version is in use.
- **Active modules** — which Plathix modules are currently registered.
- **Health checks** — known potential configuration issues detected automatically.

## How To Use It

1. Go to **Plathix → System Info** (or navigate from the Tools page).
2. Review the displayed information.
3. When contacting support, copy the relevant sections to share with the support team.

## Notes

- System Info is read-only — it shows status, it does not change any settings.
- Only Administrators can access this page.
