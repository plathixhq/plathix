# Export Folder Structure

## What It Does

Downloads your entire current folder tree as a preset ZIP package. The exported file can be imported on any other WordPress site running Plathix.

## When To Use It

- Copying a folder structure to a staging, development, or another production site.
- Creating a reusable template from an existing structure.
- Backing up your folder organization.

## How It Works

1. Go to **Plathix → Tools**.
2. Find the **Export Structure** card.
3. Click **Export to ZIP**.
4. A `.zip` file is downloaded to your computer.

The ZIP is a valid Plathix preset package and can be uploaded via **Plathix → Presets → Upload preset** on another site.

## What Gets Exported

- The full folder hierarchy (names and nesting).
- Folder positions/ordering.

## What Does Not Get Exported

- File assignments (which files belong to which folder) — those stay in the database.
- Folder colors.
- Settings or preferences.
