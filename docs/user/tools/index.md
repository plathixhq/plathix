# Tools

**Plathix → Tools** is the home for infrequent but important operations: importing from other plugins, exporting your folder structure, and managing API keys (PRO).

## What You Can Do

- [Import adapters](import-adapters.md) — import folder structure from FileBird, Real Media Library, and others
- [Export folder structure](export-structure.md) — download your folder tree as a portable preset ZIP
- [System Info](system-info.md) — diagnostic information for troubleshooting

## Notes

- The Tools page uses a card layout. Each card represents one tool or adapter.
- Plathix PRO adds an **API Keys** card for managing REST authentication tokens.
