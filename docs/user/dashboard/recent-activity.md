# Recent Activity

> **This feature requires Plathix PRO.**

## What It Does

Shows a log of recent actions in the media library: who uploaded, moved, deleted, or replaced files, and when. Helps teams track changes and audit media usage.

## How It Works

The Recent Activity widget on the dashboard is powered by the [Audit Log](../pro/audit/index.md) module in Plathix PRO. PRO writes an event to the audit log whenever a user performs a tracked action. The dashboard widget shows the most recent entries.

## In Free

In the Free version, the Recent Activity widget shows a placeholder. To see actual activity history, upgrade to Plathix PRO.
