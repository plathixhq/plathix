# Folder Statistics

## What It Does

Shows an overview of your folder structure: how many folders exist, how files are distributed, how deep the tree goes, and how many files are not assigned to any folder.

## What You See

- **Total folders** — number of user-created folders across all enabled content types.
- **Orphaned files** — files that have no folder assignment (equivalent to what you'd see in Uncategorized).
- **Maximum depth** — the deepest nesting level in your folder tree.
- **Distribution** — how files are spread across folders (for example, the number of empty folders or folders with many files).

## Notes

- System folders (Uncategorized, Trash) are not counted in "Total folders."
- Statistics are cached alongside media stats and refresh automatically.
