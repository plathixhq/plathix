# Dashboard

The Plathix Dashboard (**Plathix → Home**) gives you a quick overview of your media library status and provides shortcuts to common tasks.

## What You Can See

- [Media statistics](media-stats.md) — total file count, breakdown by type, upload activity
- [Folder statistics](folder-stats.md) — total folders, orphaned files, folder depth
- [Recent activity](recent-activity.md) — who did what and when (Plathix PRO)
- [Health notices](health-notices.md) — warnings about missing or misconfigured items
- [Quick actions](quick-actions.md) — onboarding prompts and migration suggestions

## Notes

- Statistics are cached for approximately one hour. The cache clears automatically when files are uploaded, moved, or deleted.
- The dashboard is the default landing page when you open the **Plathix** menu.
