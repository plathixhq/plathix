# ZIP Download

> **This feature requires Plathix PRO.**

## What It Does

ZIP Download lets users download all files in a Plathix folder as a single `.zip` archive directly from the Media Library. The archive is built in the background by Action Scheduler and a temporary download link is returned when it is ready.

## Requirements

- WP-Cron or Action Scheduler must be able to process jobs. If WP-Cron is disabled, the ZIP will not be generated.
- The WordPress uploads directory must have enough free disk space (approximately 1.5× the total size of the folder's files).
