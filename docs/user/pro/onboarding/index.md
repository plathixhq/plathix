# Onboarding Wizard

> **This feature requires Plathix PRO.**

## What It Does

The PRO onboarding wizard is a multi-step modal that guides Administrators through the initial Plathix configuration when they first open the Plathix dashboard. It replaces the Free preset-picker modal and covers:

1. **Content types** — which post types Plathix should manage folders for.
2. **Access** — role-based access levels and Quick Edit folder field.
3. **Structure** — apply a preset folder structure or start from scratch.

After completing or skipping the wizard, it does not reappear unless you reset it.

## What You Can Do

- [Wizard steps explained](wizard-steps.md) — what each step asks and what it saves
- [Rerun the wizard](rerun.md) — how to show the wizard again after completing it

## Notes

- The wizard only appears on the **Plathix dashboard** (Home), not on the Media Library screen.
- Only Administrators (`manage_options` capability) see the wizard.
- Without PRO, the Free preset picker (a single-step modal) is shown instead.
