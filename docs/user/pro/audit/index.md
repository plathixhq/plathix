# Audit Log

> **This feature requires Plathix PRO.**

## What It Does

The Audit Log records every significant action performed in the Plathix Media Library — who did what, when, and on which object. It helps administrators track changes, investigate incidents, and meet compliance requirements.

## What You Can Do

- [Log entries](log-entries.md) — what gets recorded and what each entry contains
- [Filter and search](filter-search.md) — find entries by action, date, or user
- [Export](export.md) — download the log as JSON or CSV
- [Retention](retention.md) — how long entries are kept and how to configure it

## Where to Find It

**Plathix → Audit Log** in the WordPress admin menu.

## Requirements

- Plathix PRO active with a valid license.
- Only users with `manage_options` capability (Administrators) can view the Audit Log page.
