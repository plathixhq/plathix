# Folder Upload

> **This feature requires Plathix PRO.**

## What It Does

Folder Upload lets you upload a local folder from your computer to WordPress and automatically recreate its subfolder structure as Plathix folders. Instead of uploading files one by one and manually creating matching folders, you select a folder (or drag it into the sidebar) and Plathix handles the rest.

## What You Can Do

- [How to upload a folder](how-to-upload.md) — step-by-step instructions
- [How folder structure is recreated](folder-structure.md) — what Plathix creates and how

## Requirements

- The **Upload folder** button appears in the sidebar toolbar only on the Media Library screen.
- The user must have at least **Upload** access level in Plathix.
- The browser must support the `webkitdirectory` input attribute (all modern desktop browsers support this).
