# Attachment Meta

> **This feature requires Plathix PRO.**

## What It Does

Attachment Meta adds a **Folder** selector in two places:

1. **The post editor sidebar** — a meta box that lets you assign a post, page, or CPT item to a Plathix folder directly from the edit screen.
2. **WordPress Quick Edit** — an optional inline folder selector in the list table's Quick Edit row.

Without this module, folder assignment for non-attachment post types is only possible from the list screen by dragging the row onto a folder in the sidebar.

## What You Can Do

- [Metabox — assign folder in the editor](metabox.md)
- [Quick Edit — assign folder inline](quick-edit.md)

## Requirements

- [Content Types](../content-types/index.md) must be active and at least one non-media post type must be enabled.
- The user must have at least **Upload** access level in Plathix.
- The meta box does not appear for the `attachment` post type (media files use the Media Library sidebar instead).
