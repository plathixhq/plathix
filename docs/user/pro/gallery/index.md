# Gallery

> **This feature requires Plathix PRO.**

## What It Does

The Gallery module adds a `[plathix_gallery]` shortcode and a Gutenberg block (`plathix/gallery`) that render media from Plathix folders on the front end. It supports multiple layout presets, a PhotoSwipe-powered lightbox, and inline video playback.

## What You Can Do

- [Shortcode reference](shortcode.md) — all attributes and their defaults
- [Shortcode builder](shortcode-builder.md) — visual GUI inside the Media Library
- [Gutenberg block](gutenberg-block.md) — block editor equivalent
- [Layout presets](layouts.md) — grid, masonry, justified, documents
- [Lightbox](lightbox.md) — full-screen image viewer with zoom, thumbnails, and download
- [Video embeds](video-embed.md) — inline video playback in a gallery
- [Sorting and filtering](sorting-filtering.md) — order, limits, folder scoping

## Requirements

- Plathix (free plugin) active
- Plathix PRO active with a valid license
- WP-Cron enabled (only for background jobs — gallery rendering does not require it)
